# 足球世界 (Football World) 

一個現代化的足球主題網站，展示足球知識、賽事信息和相關文章。

## 🌟 功能特性

- **首頁** - 吸引人的英雄區和特色卡片
- **部落格** - 詳細的足球文章和知識
- **關於我們** - 網站介紹和團隊信息
- **聯絡方式** - 聯絡表格和常見問題

## 📁 項目結構

```
football_blog/
├── index.html          # 首頁
├── blog.html           # 部落格文章頁面
├── about.html          # 關於我們頁面
├── contact.html        # 聯絡我們頁面
├── style.css           # 全局樣式表
├── script.js           # JavaScript 功能
├── football_blog.md    # 原始 Markdown 博客文章
└── README.md           # 本文件
```

## 🚀 快速開始

### 方法1：直接打開 HTML 文件

1. 使用文件管理器打開項目文件夾
2. 雙擊 `index.html` 文件
3. 網站將在默認瀏覽器中打開

### 方法2：使用 VS Code 的 Live Server 擴展

1. 在 VS Code 中打開項目文件夾
2. 安裝 "Live Server" 擴展
3. 右鍵點擊 `index.html` 並選擇 "Open with Live Server"
4. 網站將在瀏覽器中打開，並支持熱重載

### 方法3：使用 Python 簡易服務器

在項目文件夾中打開命令行，運行：

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

然後在瀏覽器中訪問 `http://localhost:8000`

## 🔧 自訂說明

### 更改顏色主題

編輯 `style.css` 中的 CSS 變數：

```css
:root {
    --primary-color: #1a73e8;      /* 主色 */
    --secondary-color: #34a853;    /* 輔助色 */
    --accent-color: #fbbc04;       /* 強調色 */
    --dark-color: #202124;         /* 暗色 */
    --light-color: #f8f9fa;        /* 淺色 */
}
```

### 編輯聯絡信息

在 `contact.html` 中更新以下信息：
- 電子郵件地址
- 電話號碼
- 物理地址
- 營業時間
- 社交媒體鏈接

### 添加新頁面

1. 創建新的 HTML 文件（例如 `gallery.html`）
2. 複製導航欄結構
3. 在所有 HTML 文件中更新導航菜單
4. 使用 `style.css` 中的類來保持一致的樣式
